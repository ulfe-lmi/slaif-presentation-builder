# Insert QR Code

## Purpose

Use this skill when a user wants a QR code inserted into an existing output.
The QR code must encode the user-provided link or text, be generated by a real
QR-code tool, and be inserted as an asset rather than hand-drawn or faked.

## Rules

- Do not create fake QR-looking patterns.
- Do not bake the QR payload into the presentation template when the template
  can accept an image path as a parameter.
- Keep the QR code as a separate image asset so it can be replaced without
  changing layout code.
- Preserve the existing design and layout unless the user asks for a redesign.
- Place the QR code in an intentionally empty region; do not cover text, logos,
  legal text, slide numbers, or important imagery.
- Use a high-contrast QR code, normally black on white.
- Include quiet-zone padding. With `qrencode`, use `-m 2` or larger unless the
  target design clearly requires more.
- Recompile and render the target page or slide after insertion.

## Workflow

1. Identify the payload exactly from the user request. For URLs, preserve the
   full scheme, for example `https://www.example.com`.
2. Install or verify a real QR generator:

   ```bash
   command -v qrencode || sudo apt-get update && sudo apt-get install -y qrencode
   ```

3. Generate the QR image into the document or deck asset directory:

   ```bash
   qrencode -o assets/example-qr.png -t PNG -s 16 -m 2 'https://www.example.com'
   ```

4. Validate the generated file:

   ```bash
   file assets/example-qr.png
   identify assets/example-qr.png
   ```

5. If the QR image renders pale or blurred after LaTeX/PDF conversion, convert
   it to an opaque RGB PNG and disable interpolation in the image placement
   helper:

   ```bash
   convert assets/example-qr.png -alpha off -type TrueColor PNG24:assets/example-qr-rgb.png
   ```

   In LaTeX, prefer `\includegraphics[interpolate=false,...]{...}` for QR code
   images.

6. Insert the QR image through the existing template or image-placement helper.
   Prefer an optional macro argument when the QR code is optional:

   ```tex
   \FinalSlide[example-qr.png]{Thank you}
   ```

7. Size and position by visual balance:
   - align the QR code to the center of the intended empty region
   - keep enough white space around it for scanning
   - make it large enough to scan in the final medium
   - when the user gives a relative size, compare against the visible bounding
     box of the referenced visual element, not the full slide

8. Recompile, render the affected page or slide, and inspect the image before
   reporting completion.

## Beamer Notes

- If the deck uses an image helper that prepends an asset directory, pass only
  the asset filename to the macro and store the file in that asset directory.
- Keep layout constants in the style file or template macro. Keep the payload
  image path in the slide source when the user may replace it later.
- If no QR is supplied, the optional argument should render nothing and leave
  the existing slide unchanged.
